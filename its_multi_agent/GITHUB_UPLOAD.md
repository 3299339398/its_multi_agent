# GitHub 提交前检查

真实凭据保存在本地 `backend/app/.env`、`backend/knowledge/.env`，Docker Compose 使用项目根目录 `.env`。公开配置模板为 `.env.example`；不要将真实密钥填入模板，也不要使用 `git add -f` 强制提交被忽略的文件。

环境配置、加密私钥、模型凭据数据库、日志、会话归档和文件产物属于本地运行数据，应保持在 Git 之外。本次清理仅取消运行数据的 Git 跟踪，保留磁盘文件。

暂存要提交的代码后，从仓库根目录执行：

```powershell
python its_multi_agent/scripts/check_secrets.py
git diff --cached --stat
```

检查脚本扫描暂存内容中的常见令牌格式，并与本地环境配置中的敏感值进行比对，只输出文件名，不输出凭据。发现问题时退出码为 1。它不是完整秘密检测器，不检查 Git 历史，也不能替代对配置、截图和文档的人工审查。

旧提交仍可能包含已取消跟踪的日志、会话和数据库；新的删除提交不会清除旧历史。若要将仓库公开，应先处理这些历史运行数据，或者将清理后的代码导入一个不携带旧历史的新仓库。若发现密钥曾经公开，应先在供应商侧撤销并换新。
